# mahdi-abdurrahman

#### <p>This repository contains a portfolio website for <strong>Mahdi Abdurrahman</strong> a <em>Software and Web Developer</em>,<br> showcasing his soft and technical skills with e-commerce solutions, websites, and web applications.</p>

## Features
- HTMl5, CSS3, and JavaScript application
- Utilizing Semantic HTML5 elements
- Responsive design layout with Flexbox and CSS Grid
- Interactive CSS Animations
- Interactive validation for contact form
- Hover effects and transitions


### To Use
Clone or Download the repository
`git clone  https://github.com/MAbdurahman/mahdi-abdurrahman.git`

### Install the dependencies

`npm install or yarn`

### To start the project

`npm run start or yarn start`

### To build the project, run the following command

`npm run build or yarn build`
